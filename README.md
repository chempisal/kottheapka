# កម្មវិធី កត់ខ្នាតធៀបការ (Wedding Invitation Sizes & Orders Mobile Web App)

កម្មវិធីកត់ត្រាខ្នាតធៀបការ ខ្នាតស្រោមសំបុត្រ និងគ្រប់គ្រងការកុម្ម៉ង់ធៀបការលើទូរស័ព្ទដៃ ដែលបង្កើតឡើងដោយយកលំនាំតាម Glide App (`pisal.glide.page/dl/7e4bba`)។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

1. **កត់ត្រា និងគណនាខ្នាតធៀបស្វ័យប្រវត្ត (Smart Measurement Tool)**
   - **ក្របមុខ (Cover) :** កម្ពស់ (Height) និង ទទឹង (Width)
   - **ស្រោមលុយ (Money Envelope) :** កម្ពស់ (Height) និង ទទឹង (Width)
   - **សាច់ក្នុង (Inner Insert) :** កម្ពស់ (Height) និង ទទឹង (Width)
   - ជ្រើសរើសខ្នាតស្តង់ដាររហ័ស (18×13 cm, 17×12 cm, 20×15 cm, 20×10 cm, 14×14 cm)
   - មុខងារគណនាខ្នាតស្រោមលុយ និងសាច់ក្នុងដោយស្វ័យប្រវត្តពីក្របមុខ (Auto Calculate)
   - កត់ត្រាទម្រង់បត់ធៀប (បត់២, បត់៣, សន្លឹកទោល, ធៀបប្រអប់, អាក្រីលិក)
   - ពណ៌ស្រោមសំបុត្រ និងប្រភេទក្រដាស
   - បច្ចេកទេសពិសេស (ស្ពាន់ទឹកមាស, ស្ពាន់ទឹកប្រាក់, អក្សរផុស, ត្រាក្រមួន, ចងបូ)

2. **គណនាតម្លៃ និងប្រាក់កក់ស្វ័យប្រវត្ត (Auto Price & Financials)**
   - គណនាតម្លៃសរុប = ចំនួនធៀប × តម្លៃក្នុងមួយសន្លឹក
   - គណនាប្រាក់នៅសល់ = តម្លៃសរុប - ប្រាក់កក់
   - តាមដានស្ថានភាពទូទាត់ (បានបង់គ្រប់ ឬនៅជំពាក់)

3. **សន្លឹកកត់ខ្នាត និងវិក្កយបត្រ (Workshop Cutting Slip & Receipt)**
   - បង្ហាញសន្លឹកកត់ខ្នាតច្បាស់លាស់សម្រាប់ជាងកាត់រោងពុម្ព
   - អាចបោះពុម្ព (Print) ជាក្រដាស ឬរក្សាទុកជា PDF
   - អាចផ្ញើទិន្នន័យផ្ទាល់ទៅកាន់ **Telegram** ដោយចុចតែមួយប៉ូតុង

4. **ការគ្រប់គ្រង និងតាមដាន (Order Management & Analytics)**
   - ស្វែងរកតាមឈ្មោះកូនកំលោះ ក្រមុំ លេខទូរស័ព្ទ និងលេខកូដធៀប
   - តម្រងតាមស្ថានភាព (រង់ចាំ, កំពុងផលិត, រួចរាល់, បានប្រគល់)
   - ផ្ទាំងស្ថិតិបង្ហាញចំណូលសរុប ចំនួនសន្លឹកធៀប និងប្រាក់នៅជំពាក់
   - កាលវិភាគប្រគល់ធៀបការជិតមកដល់

5. **ដំណើរការលើទូរស័ព្ទដៃបានយ៉ាងរលូន (Mobile PWA & Offline Support)**
   - រចនាឡើងជាទម្រង់ Mobile-First (Glide / iOS Native App Experience)
   - គាំទ្រ Dark Mode និង Light Mode
   - រក្សាទុកទិន្នន័យក្នុង LocalStorage មិនបាត់បង់ទោះបិទទូរស័ព្ទ
   - អាចទាញយកឯកសារបម្រុងទុក (Backup JSON) និងបញ្ចូលឡើងវិញ (Restore)

## 💾 ប្រព័ន្ធមូលទិន្នន័យ (Database Architecture)

កម្មវិធីនេះគាំទ្រ **Dual Database Architecture (SQLite Server + LocalStorage Sync)**៖

1. **SQLite Database (`database.db`)**
   - ផ្ទុកទិន្នន័យលើ Server យ៉ាងមានសុវត្ថិភាពក្នុងឯកសារ `f:/KOT/database.db`
   - គ្រប់ទូរស័ព្ទដៃ ឬកុំព្យូទ័រដែលបើកកម្មវិធី នឹងធ្វើសមកាលកម្ម (Sync) ទិន្នន័យរួមគ្នាភ្លាមៗ (Real-time Multi-device Sync)
   - រាល់ការ បន្ថែម, កែសម្រួល, ឬលុប នឹងត្រូវកត់ត្រាចូលក្នុងតារាង `orders` និង `settings` នៃ SQLite ដោយស្វ័យប្រវត្ត
2. **Offline LocalStorage Cache**
   - ទោះបីជាទូរស័ព្ទដាច់ Wi-Fi ឬបិទ Server ក៏ទូរស័ព្ទដៃនៅតែអាចបើកមើលទិន្នន័យចាស់ៗបានធម្មតា

## 🚀 របៀបបើកដំណើរការ Server & Database

បើក Terminal / PowerShell ក្នុងថត `f:\KOT` រួចវាយបញ្ជា៖
```bash
python server.py
```
បន្ទាប់មកអ្នកនឹងឃើញ៖
- 💻 **លើកុំព្យូទ័រ (Localhost):** `http://localhost:8080`
- 📱 **លើទូរស័ព្ទដៃ (Wi-Fi):** `http://<IP-កុំព្យូទ័ររបស់អ្នក>:8080` (ឧ. `http://192.168.1.50:8080`)
